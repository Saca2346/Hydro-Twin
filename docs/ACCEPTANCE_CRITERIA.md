# ACCEPTANCE_CRITERIA.md

## Global
- Semua UI berbahasa Indonesia.
- Responsif pada 1440, 1024, dan 390 px.
- Tidak ada horizontal overflow.
- Contrast minimum WCAG AA.
- Keyboard focus terlihat.
- Status selalu memiliki teks dan ikon.
- Provenance data terlihat pada semua halaman dengan angka.

## Evaluasi Model
- Tidak ada angka dummy.
- State awal `Belum diuji`.
- Angka hanya muncul dari data API.
- Tanggal evaluasi dan dataset ID ditampilkan.

## Alarm
- Kolom tidak overlap.
- Menampilkan alasan, durasi, kualitas data, status, dan aksi.
- Alarm invalid data tidak boleh menghasilkan rekomendasi inspeksi.
- Konfirmasi operator tercatat.

## Digital Twin
- Skema 2D.
- Komponen dapat diklik.
- Tidak ada klaim 3D.
- Detail komponen menampilkan status dan sensor terkait.

## Proposal
Setiap gambar UI yang diekspor memiliki caption:
“Data yang ditampilkan merupakan data simulasi untuk demonstrasi antarmuka dan bukan hasil eksperimen.”
