# Hydro-Twin — Antigravity Workspace

Dokumen ini adalah titik mulai implementasi dashboard Hydro-Twin di Google Antigravity.

## Cara menggunakan

1. Ekstrak folder ini.
2. Buka Antigravity dan buat workspace baru dengan root folder ini.
3. Buka Agent Manager.
4. Jalankan prompt pada `prompts/01-bootstrap.md`.
5. Setelah aplikasi berhasil berjalan, lanjutkan prompt secara berurutan:
   - `02-design-system.md`
   - `03-core-pages.md`
   - `04-data-and-state.md`
   - `05-validation.md`
6. Gunakan gambar pada folder `references/` sebagai sumber visual utama.
7. Jangan mengubah angka simulasi menjadi klaim hasil penelitian.
