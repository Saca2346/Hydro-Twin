5. Buat shell aplikasi: sidebar, topbar, routing, responsive layout.

7. Tambahkan mock provenance `simulation`.
8. Jalankan dev server dan tampilkan aplikasi pada integrated browser.
9. Jangan membangun semua halaman sekaligus.
10. Setelah selesai, laporkan file yang dibuat, command yang dijalankan, dan error yang tersisa.
