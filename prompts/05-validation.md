# Prompt 05 — Validation

Lakukan quality gate:
1. Jalankan lint, test, typecheck, dan production build.
2. Periksa desktop 1440 px, tablet 1024 px, mobile 390 px.
3. Periksa keyboard navigation dan focus state.
4. Periksa contrast.
5. Pastikan tidak ada horizontal overflow.
6. Pastikan semua angka contoh berlabel data simulasi.
7. Pastikan Evaluasi Model default Belum diuji.
8. Pastikan alarm invalid data tidak menghasilkan rekomendasi.
9. Pastikan tidak ada istilah pressure drop/residual tanpa padanan UI Bahasa Indonesia.
10. Buat `VALIDATION_REPORT.md` yang mencatat hasil pemeriksaan dan masalah tersisa.
11. Jalankan integrated browser dan ambil screenshot final untuk setiap halaman utama.
